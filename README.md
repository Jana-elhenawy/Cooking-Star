# 🍳 Cooking Star

Cooking Star is a modern recipe-sharing and meal discovery platform that helps users explore, search, save, and manage cooking recipes. The platform allows users to browse recipes, view detailed cooking instructions, and discover new dishes while providing administrators with tools to manage recipe content.

---

## 🌟 Features

### 👨‍🍳 Recipe Management
- Browse recipe collections
- View recipe details
- Search recipes by name
- Filter recipes by category
- Display ingredients and cooking instructions

### 🔍 Recipe Search
- Fast recipe search
- Category-based filtering
- Dynamic search results
- Database-driven recipe retrieval

### 👤 User Management
- User registration
- Secure login and authentication
- User profile management
- Personal recipe collections

### ❤️ Favorites System
- Save favorite recipes
- View saved recipes
- Remove recipes from favorites

### 🛠️ Admin Dashboard
- Add new recipes
- Edit existing recipes
- Delete recipes
- Manage recipe categories
- Manage user-generated content

### 📱 Responsive Design
- Mobile-friendly interface
- Modern UI/UX
- Easy navigation

---

## 🚀 Project Objectives

- Help users discover new recipes
- Provide a centralized recipe platform
- Simplify recipe management
- Enable administrators to maintain recipe content efficiently
- Improve user cooking experience
